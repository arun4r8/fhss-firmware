## After reseating the CAN pins (both boards, 48 MHz)

Self-test: both boards pass every check, including the MCP2515 loopback.

| Board | Noise floor (min / avg / max dBm) | TX 30 B (expected 72 ms) |
|---|---|---|
| Pod | −102 / −99 / −93 | 73 73 73 73 74 |
| Ground | −100 / −93 / −86 | 73 73 74 74 73 |

Live link (pod in CAN demo mode, ground sending a command every hop): 5 frames/s, 0 missed, 0 CRC errors over 265 frames. Typed `s3` on the ground:
```
STATE,32516,3,3,592
status: locked, frames 265, missed 0, bad 0, crc errors 0, state target 3 pod 3 (confirmed), cmds sent 133
```
The pod received 137 of the 137 commands sent. The ground's "CAN resend errors" count is expected: nothing on its CAN bus ACKs the frames it forwards (the real two-board bus still gets no ACK; transceiver wiring is the suspect).
